# ProjectForge
ProjectForge is an AI-powered CLI tool that helps students turn project ideas into structured, implementation-ready college project blueprints. It uses specialized Skills for requirements analysis, architecture, database design, API planning, and project planning, with users providing their own AI API keys through .env.  The project is designed to evolve in three stages:  Skills → DevAgent → Engineering Harness  The long-term goal is to evolve ProjectForge from an AI-assisted project builder into an autonomous software engineering system capable of turning requirements into tested, review-ready applications.
